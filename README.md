# Music Explorer

Native Android app for the Music Explorer handout.

## Run in Android Studio

1. Open the project folder in Android Studio
2. Get a free Last.fm API key from <https://www.last.fm/api/account/create>.
3.Sync Gradle.
4. Choose an emulator and press Run.

## Features

- Material Design 3 UI with top app bar, bottom navigation, cards, chips, buttons, and FAB.
- Browse global top artists and search for any artist.
- Artist detail with biography, listeners, top tracks, top albums, similar artists, save, and share.
- Offline and error states with retry actions.
- Room database for saved artists.
- RecyclerView lists on Browse, Artist Detail, and My Collection screens.
